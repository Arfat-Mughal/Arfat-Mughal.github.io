Data-driven decisions

Copilot Studio manages the conversation and Adaptive Cards. Dataverse holds the taxonomy, departments, cost centres, GL accounts, dimensions, travel policy, and approval thresholds alongside supplier, catalogue, routing, and audit data. Classification, coding, and routing read this configuration rather than hardcoded agent rules.

Workflow orchestration

Four Power Automate flows handle financial coding and rate-card estimates, buying-route resolution and audit logging, requisition creation, and escalation when the purchase value is unknown. Routes include preferred supplier, catalogue, P-card, sourcing, and escalation.

Approvals & administration

Teams delivers approval cards to the Procurement Leads channel. The demo creates requisitions and purchase orders in Dynamics 365 Finance & Operations. An Entra ID sign-in connects the branded web experience, while a Power Apps admin app supports editing buying requests, catalogue entries, and routing rules.

Tested demo, with next steps defined

The end-to-end demo passed 18 of 18 tests. Planned work includes moving requisitions to Dataverse, sending approvals directly to the assigned approver, replacing the fixed demo requester with signed-in user data, and adding the new configuration tables to the admin app.

Invoice Genie · AI invoice review

Upload an invoice PDF or a batch of up to 50. AI extracts supplier details, amounts, purchase order references, and line items, then checks them against NetSuite. Around 27 outcomes cover matches, price or quantity differences, duplicate invoices, receipt and balance issues, and credit memos. The workflow supports two-way and three-way matching for blanket and service purchase orders.

Human review & approval

Reviewers can override a result, return it to the vendor, route it to purchasing, or add a review note to the NetSuite purchase order. Approval decisions trigger notifications, and invoice results and posting history remain searchable. Vendor-bill creation and editing are supported, subject to company posting controls; posting is currently disabled.

SOW Genie · AI document drafting

Creates Statements of Work from templates using AI, stores the contracts, and links documents to SharePoint. Administrators can review contracts and their files from the admin panel.

Teams, access & administration

Company-separated data, account-level team limits, and product access for Invoice Genie, SOW Genie, or both. Super Admin, Admin, Manager, and User roles support company-scoped records and team activity views. Administration includes approval rules, integration status, audit logs, AI model settings, support tickets, and reports.

Release safeguards

Moved environment settings out of container images and into runtime configuration. Added encryption-key consistency checks, deployment locking, database backups, readiness checks, and automatic rollback for the frontend and backend. Fixed GraphQL URL handling, HTTPS admin login, and database-failure readiness responses.

An isolated staging environment

Delivered a separate website, API, admin panel, database, settings, and storage with automatic staging deployments. Masked personal data in the staging copy and used a restricted database user to separate staging access from production data.

Company-level ERP controls

Added immediate, audited controls for enabling or disabling NetSuite posting per company. The checks cover write operations, including approval flows, with a global emergency switch available to administrators.

Integration configuration

The platform uses Claude API for invoice classification and extraction, Microsoft Graph for SharePoint documents, Ramp for spend workflows, and Cloudflare Turnstile for public forms. My delivery included environment-specific integration configuration. NetSuite connection validation and reconnection remain follow-up work.
