Case study · AI business tools & platform delivery

GenieWorks

A platform for AI-assisted invoice review and Statement of Work creation, supported by controlled releases, isolated staging, and company-level ERP safeguards.

The challenge

The platform needed to handle invoice and document workflows while deployments remained dependable, staging stayed separated from production data, and administrators could immediately control sensitive NetSuite posting activity per company.

What I delivered

Invoice Genie

AI extracts data from single or batch invoice PDFs, checks them against NetSuite purchase orders, supports matching and review workflows, and keeps invoice outcomes searchable. Posting remains controlled at company level.

SOW Genie

AI drafts Statements of Work from templates, links contracts to SharePoint, and provides administrators with a clear contract and file view.

Reliable releases

GitHub Actions builds versioned Laravel and Next.js container images. Deployments run migrations, validate health, protect encryption-key consistency, back up data, lock concurrent releases, and roll back on failure.

Safe administration

Company-separated data, role-based product access, approval rules, integration status, audit logs, and an immediate switch for enabling or disabling NetSuite posting per company.

Release workflow

  1. Review. Changes move through pull requests.
  2. Build. CI checks deploy scripts and builds container images away from the deployment host.
  3. Deploy. Versioned images are pulled, migrations are applied, and settings remain runtime configuration.
  4. Verify. Health checks confirm the service and trigger automatic rollback if required.

Staging and integrations

The staging environment is a full isolated copy with masked data, separate database access, settings, and storage. The platform connects NetSuite, Claude for invoice extraction and classification, Microsoft Graph for SharePoint documents, Ramp spend workflows, and Cloudflare Turnstile for public forms. NetSuite reconnection and validation remain follow-up work.

Technology

Laravel · Next.js · Docker · GitHub Actions · GitHub Container Registry · MySQL · nginx · NetSuite · Microsoft Graph / SharePoint · Claude API · Cloudflare Turnstile
